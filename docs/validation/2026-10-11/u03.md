# U03 recovery implementation evidence

Shell helper `scripts/itworks-recovery.sh` implements explicit snapshot,
staging-copy, verify-before-write, restore-to-empty, and approved-stage apply.
`references/upgrade-recovery.md` marked shell blocks invoke that same helper;
integration tests extract and execute those exact blocks. No Python runtime or
semantic migration is added. Snapshot includes independent bytes/modes, project
Git metadata, plugin manifest/runtime identities, resolved roots, and retention.

Source symlinks/special paths, internal destinations, unverified/tampered backups,
existing destinations and concurrent source changes fail closed. Backups are
private and never overwritten. Apply validates staging, independently rehearses
restore, checks source immediately before writes, and uses deterministic per-file
replacement. Partial/final-validation failure retains failed state and restores
verified original bytes. Failed restore retains every independent recovery source
and requests manual recovery. Multiple files are not atomic: writers must pause;
power loss/SIGKILL still requires manual restore from retained backup.
